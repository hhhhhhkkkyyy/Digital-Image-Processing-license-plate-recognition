# 车牌识别系统 (License Plate Recognition)

基于 OpenCV 和模板匹配的中国车牌识别系统，包含图形化界面，支持车牌定位、字符分割和字符识别全流程。

## 功能特性

- **车牌定位**：基于 HSV 颜色空间 + 形态学处理 + 边缘检测，精准定位蓝色车牌
- **透视校正**：四点透视变换，校正倾斜车牌
- **字符分割**：等宽切割法，稳定分割 7 个车牌字符
- **字符识别**：模板匹配算法，支持数字、字母及 31 个省份简称
- **GUI 界面**：Tkinter 图形界面，分步展示处理过程
- **实时可视化**：原始图、处理图、车牌图三栏对比显示

## 技术栈

- Python 3.x
- OpenCV (cv2)
- NumPy
- Pillow (PIL)
- Tkinter

## 使用方法

1. 运行程序：
   ```bash
   python car_plate_recognition.py
   ```
2. 点击 **加载图像**，选择包含车牌的图片（支持 jpg / png / bmp / tif）
3. 依次点击按钮执行识别流程：
   - **车牌定位**：在原图中用红框标出车牌位置
   - **车牌提取**：单独显示校正后的车牌图像
   - **字符分割**：将车牌切分为 7 个独立字符
   - **字符识别**：逐字符匹配模板并输出最终识别结果
4. 识别结果显示在左侧面板的「识别结果」区域

## 识别流程说明

| 步骤 | 方法 | 说明 |
|------|------|------|
| 定位 | HSV 蓝色阈值 + 形态学 + Canny 边缘 | 根据宽高比（≈3.14:1）筛选最佳轮廓 |
| 校正 | 四点透视变换 (four_point_transform) | 将倾斜车牌校正为水平矩形 |
| 分割 | 竖直投影 + 等宽切割 | 保证 7 个字符不偏位 |
| 识别 | 模板匹配 (TM_CCOEFF_NORMED) | 多预处理变体 + 正反模板匹配，取最高分 |

## 模板说明

模板目录按字符名分类存放，每个子目录下可包含多张同字符不同字体/样式的模板图片。程序加载时取该目录下第一张图片作为模板。

支持字符：
- 数字：0-9
- 字母：A-Z（不含 I、O，符合车牌规范）
- 省份：京、津、冀、晋、蒙、辽、吉、黑、沪、苏、浙、皖、闽、赣、鲁、豫、鄂、湘、粤、桂、琼、渝、川、贵、云、藏、陕、甘、青、宁、新

## 注意事项

- 目前仅支持**蓝色车牌**（小型汽车）识别
- 车牌在图像中应清晰可见，无严重遮挡或模糊
- 识别准确率依赖模板质量，可自行扩充 `templates/` 目录下的模板
- 建议图片中车牌占比不小于图像面积的 0.5%
